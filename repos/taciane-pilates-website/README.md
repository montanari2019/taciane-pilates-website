# Taciane Pilates Website

Site do Estúdio de Pilates Taciane Martins (Vilhena-RO). Next.js (App Router) + TypeScript + CSS Modules. Só a base: estrutura, tokens da identidade visual e um componente de exemplo.

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint
npm run check:style
npm run build
```

Regras de estilo (tokens de cor, `globals.css`, `styles.module.css`, nunca CSS inline) e estrutura de pastas: veja [CLAUDE.md](CLAUDE.md).

Copie `.env.example` para `.env.local` para configurar variáveis (WhatsApp, Instagram, Facebook, URL do site).
